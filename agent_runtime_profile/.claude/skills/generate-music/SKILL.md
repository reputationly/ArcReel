# 生成音乐

按曲风描述作一首曲子，落到项目 `music/` 目录。产物是**项目级单件**——一支片子一首曲，
固定 resource_id `main`，重复生成覆盖同一份，不像旁白那样按分镜逐条产出。

## 工具调用

**重要：生成音乐必须调用下列 MCP 工具入队。此 skill 不提供任何 Python/Shell 脚本。**

| 操作 | 工具 |
|------|------|
| 生成配乐 | `mcp__arcreel__generate_music({"prompt": "舒缓的钢琴独奏，忧郁，60BPM"})` |
| 指定时长 | `mcp__arcreel__generate_music({"prompt": "...", "duration_seconds": 30})` |

> **prompt 怎么写**：风格 + 情绪 + 乐器 + 节奏四要素。空描述会被工具拒绝——引擎会自由
> 发挥，产出与项目无关的曲子且照常计费。
>
> **duration_seconds 留空**由引擎决定。填了也**以回包实测时长为准**：引擎产出未必等于
> 申请值，工具会报出实测值。
>
> **依赖**：generation worker 在线（音乐与旁白共用 audio 通道）；音乐模型需在设置页
> 配好——它与旁白配音是两个不同的模型，配了 TTS 不等于能作曲。

## MV 项目的顺序

**先出音乐，再写剧本。** MV 的时间轴由歌曲决定：镜头时长不是创作选择，是音乐段落的
产物。顺序反了会让镜头与歌曲对不上，只能推倒重排。

```
音乐 → 剧本（按歌的段落与实测时长分配镜头）→ 资产图 → 分镜图 → 视频
```

其余内容模式（narration / drama / ad）没有这个约束，音乐只是 BGM，任何时候生成都行。

## 错误处理

- 工具提示未配置音乐模型时，引导用户到 Web 设置页配置后重试
- 生成失败原样上报错误，不重试——作曲失败通常是模型未部署或描述被引擎拒绝，重试无用
